# ETF 网格参数优化工具（Python WebUI）

下载历史K线 → 分析涨跌幅/振幅分布 → 回测并搜索 **短线 / 中线 / 长线** 各自最优网格参数（基价 / 区间触发 / 确认阈值），Web 界面可视化展示。

## 一、功能
1. **下载历史K线**：输入 ETF 代码（如 513310、513180），自动下载上市以来全部日K（腾讯行情接口，自带重试）。
2. **涨跌幅分析**：每日涨跌幅、振幅的均值与百分位分布、最大单日涨跌。
3. **最优网格参数搜索（短/中/长）**：
   - **短线**：网格间距取日涨跌幅绝对值 P45~P60 分位，基价取近 20 日均线
   - **中线**：网格间距取 P60~P75 分位，基价取近 60 日均线
   - **长线**：网格间距取 P75~P88 分位，基价取近 120 日均线
   - 每个周期在分位区间内搜索，用**历史网格回测**（每笔独立配对、含手续费、含持仓风控上限）评分，选出回测收益率最优的「区间触发 + 确认阈值」组合。
4. **WebUI**：ECharts 绘制 K 线图、涨跌幅分位分布柱状图；卡片式展示三周期最优参数与回测明细。

## 二、安装与启动
```bash
cd etf-grid-optimizer
pip install -r requirements.txt
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

## 三、使用方法
页面顶部表单填写：
- **ETF代码**：如 `513310`（中韩芯片）/ `513180`（恒生科技）
- **起始/结束日期**：可选，留空取全部历史
- **基价系数**：基价 = 均线 × 该系数（默认 1，可微调基价高低）
- **网格层数**：最多向下叠加几档买入（默认 5）

点击「开始分析」即出结果。

## 四、输出解读
三张卡片对应短线/中线/长线，各自给出：
- **基价**：网格中枢价（网格以此为轴）
- **区间触发**：每档网格价格间隔（下跌到该档后反弹确认即买入）
- **确认阈值**：反弹/回落确认幅度（避免毛刺假触发）
- **回测明细**：回测收益率、交易次数、最大持仓、已实现/期末浮动盈亏

示例（513310 中韩芯片，914 根日K）：
| 周期 | 基价 | 区间触发 | 确认阈值 | 回测收益率 | 交易次数 |
|------|------|---------|---------|-----------|---------|
| 短线 | 4.7772 | 1.44% | 0.14% | +1.51% | 15 |
| 中线 | 4.9293 | 2.16% | 0.22% | +1.84% | 28 |
| 长线 | 5.1415 | 2.83% | 0.23% | +2.50% | 24 |

## 五、项目结构
```
etf-grid-optimizer/
├── app.py              # Flask 入口 / API
├── data_fetcher.py     # K线下载（腾讯主源 + akshare 备用）
├── grid_optimizer.py   # 涨跌幅分析 / 参数搜索 / 网格回测
├── templates/index.html# WebUI（ECharts）
└── requirements.txt
```

## 六、说明与风险
- 数据源：腾讯行情（默认）、akshare 东财（备用，若网络拦截则不可用）。
- 回测模型：固定每笔 1 万元、单边手续费 0.05%、最大持仓 10 份，可改 `grid_optimizer.py` 顶部常量。
- 网格交易无法规避单边下跌风险，结果仅供策略研究，**不构成投资建议**。
