# ETF 网格交易工具（Python WebUI）

一个应用两个功能页面（顶部 Tab 切换）：

| Tab | 数据 | 功能 |
|-----|------|------|
| 📈 **日K 参数优化**（`/`） | 日K | 分析涨跌幅/振幅 → 搜索**短/中/长**最优网格参数（基价/区间触发/确认阈值） |
| ⏱ **5分钟 触网确认回测**（`/backtest5`） | 5分钟K线 | 手动输入**基价/网格区间%/确认阈值%**，执行「触网标记 + 反向确认成交」策略回测 |

---

## 一、Tab1：日K 参数优化

下载历史K线 → 分析涨跌幅/振幅分布 → 回测并搜索 **短线 / 中线 / 长线** 各自最优网格参数。

1. **下载历史K线**：输入 ETF 代码（如 513310、513180），自动下载上市以来全部日K（腾讯行情接口，自带重试）。
2. **涨跌幅分析**：每日涨跌幅、振幅的均值与百分位分布、最大单日涨跌。
3. **最优网格参数搜索（短/中/长）**：
   - **短线**：网格间距取日涨跌幅绝对值 P45~P60 分位，基价取近 20 日均线
   - **中线**：网格间距取 P60~P75 分位，基价取近 60 日均线
   - **长线**：网格间距取 P75~P88 分位，基价取近 120 日均线
   - 每个周期在分位区间内搜索，用**历史网格回测**（每笔独立配对、含手续费、含持仓风控上限）评分，选出回测收益率最优的「区间触发 + 确认阈值」组合。
4. **WebUI**：ECharts 绘制 K 线图、涨跌幅分位分布柱状图；卡片式展示三周期最优参数与回测明细。

**页面表单**：ETF代码、起始/结束日期（可选）、基价系数（= 均线×系数）、网格层数。

## 二、Tab2：5分钟 触网标记 + 反向确认成交 回测

按用户定义的**时序规则**回测（事件驱动，逐根5分钟K线）：

- **买入**：价格跌破网格线 `基价×(1-区间%)` **仅标记**（不下单）；此后价格反弹回到 `网格线×(1+确认%)` **才下单买入**
- **卖出**：价格涨破卖出网格线 `买入价×(1+区间%)` **仅标记**；此后价格回落 `卖出网格线×(1-确认%)` **才下单卖出**
- **手续费**：万1，单笔保底 0.1 元

**页面表单**：ETF代码、**基价**、**网格区间(%)**、**确认阈值(%)**、每笔金额、初始资金、最大持仓、K线根数。

**输出**：K线图（叠加网格线+买入/卖出点）、净值曲线、指标卡（收益率/总盈亏/买卖次数/最大持仓/已实现与浮动盈亏）、交易日志表。

> ⚠️ 使用提示：基价建议设在行情区间**偏上沿**（页面会显示实时最低/最高/最新价），否则向下网格线够不到，行情低位时可能 0 成交（属正常行为）。单边阴跌行情下，反弹若达不到确认阈值会「只买不卖」被动套牢——策略只能过滤毛刺，规避不了单边趋势风险。

## 三、安装与启动
```bash
cd etf-grid-optimizer
pip install -r requirements.txt
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

## 四、项目结构
```
etf-grid-optimizer/
├── app.py                    # Flask 统一入口 / API（两个路由）
├── data_fetcher.py           # 日K 下载（腾讯主源 + akshare 备用）
├── grid_optimizer.py         # 日K 涨跌幅分析 / 参数搜索 / 回测
├── data_fetcher_min.py       # 5分钟K线下载（腾讯 ifzq 接口）
├── grid_engine_5min.py       # 5分钟 触网标记+反向确认成交 回测引擎
├── templates/
│   ├── index.html            # Tab1 日K 参数优化（WebUI，ECharts）
│   └── index_5min.html       # Tab2 5分钟 回测（WebUI，ECharts）
└── requirements.txt
```

## 五、说明与风险
- 数据源：腾讯行情（默认）；akshare 东财为日K备用源（若网络拦截则不可用）。
- 回测模型（Tab1）：固定每笔 1 万元、单边手续费 0.05%、最大持仓 10 份，可改 `grid_optimizer.py` 顶部常量。
- 回测模型（Tab2）：手续费万1、单笔保底 0.1 元，参数均在页面可调。
- 网格交易无法规避单边下跌风险，结果仅供策略研究，**不构成投资建议**。
